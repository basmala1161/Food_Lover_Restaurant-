 🍽️ Food Lover Restaurant Website

A clean and elegant restaurant website using HTML and CSS, designed to highlight dishes, ambiance, and simplify table booking.

 🌐 Website Sections
- **Home** – Hero section with "Book a Table" CTA
- **About** – Info about the restaurant's story and values
- **Menu** – List of dishes with categories
- **Gallery** – Attractive food and interior photos
- **Contact** – Location, form, and contact details

✨ Features
- Responsive layout for all devices
- "Book a Table" button for reservations
- Smooth section navigation
- Custom CSS design

 📁 Project Files
- `index.html` – Main homepage with all sections
- `style.css` – Styling for layout, colors, and responsiveness
- `full.rar` – Compressed folder with all assets and code

 🚀 How to Run
1. Download or extract `full.rar`
2. Open `index.html` in your browser
